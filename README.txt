ZayStaff 2.0 - staff toolkit, automod and anti-cheat for Paper + Geyser

BUILD (no terminal needed):
 1. Unzip this on your PC.
 2. github.com -> New repository (Public) -> Create.
 3. "uploading an existing file" -> drag EVERYTHING from the unzipped folder in (including the .github folder) -> Commit.
 4. Actions tab -> wait for the green tick -> open the run -> download "ZayStaff" under Artifacts.

INSTALL:
 Put ZayStaff.jar in  C:\Users\zay_m\Downloads\Java 2\plugins\
 Type  stop  in the console, then run start.bat again.
 NOTE: delete the old plugins\ZayStaff folder first if you installed 1.0 (config changed).

X-RAY (Paper built-in): Java 2\config\paper-world-defaults.yml
   anticheat:
     anti-xray:
       enabled: true
       engine-mode: 2
